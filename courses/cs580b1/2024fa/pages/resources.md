### Minimum Resources Required

Students must have adequate computing resources able to do the following:
* You must have a Colorado State University Identity (NetID), before you can be installed into the CS580B1 Canvas system. If you don't have one, visit the [**eIdentity and eServices web page**](http://www.eid.colostate.edu/). You will not be able to take part in the course until you have an NetID.
* Access the class [**Canvas**](https://canvas.colostate.edu/) page. Students must use a browser installed on their computer that is compatible with [**Canvas**](https://canvas.colostate.edu/). Browsers are generally available for free.
* To keep things simple for students, we will use Canvas for (1) disseminating slides, (2) all submissions of paper reviews and project materials, and (3) posting grades. The schedule for the course will be available on the course website.
* Lectures will be held in person. 
* We will use Microsoft Teams for all discussion. Install the Microsoft Teams app on our phone or desktop. Use your-eid@colostate.edu and password to log in. You can chat using text, audio, and video. You can also use Teams in a web browser. Go to [**login.microsoftonline.com**](http://login.microsoftonline.com) and use your-eid@colostate.edu and password to log in. Click on Apps to locate the Teams app.

### Connecting to CS Machines

Using departmental machines is optional. You can do all your work on your personal machines.

There are several linux machines named after state capitals (e.g., salem.cs.colostate.edu, denver, etc) that you can connect to. You must have an ssh client on your machine. For windows, you can install putty or Bitvise SSH client.  Linux machines and macs come with ssh. A VPN is required to connect to the CS machines. You can transfer files from departmental machines to yours using sftp or the same Bitvise SSH client. You can get the directions for remote connections [**here**](https://sna.cs.colostate.edu/remote-connection/).

### Software Tools

The paper reviews and the project report need to be typeset using [LaTeX](https://www.latex-project.org/). This is the only software tool you will need for this course (apart from tools needed for your project). You can either install LaTeX locally or access it in a web browser via [Overleaf](https://www.overleaf.com/).
